**Detailed Description (English)** [REQUIRED]
Sidekick (翻翻) is a privacy-first AI reading, watching, and browsing companion that translates web pages and video subtitles side-by-side, summarizes articles and PDFs with clickable citations, and answers questions in your browser side panel using your own AI API key.

Key Features:
• Bilingual Web Page Translation: Read translations right below each paragraph or switch to translation-only mode with one click. Hover over any paragraph and tap Shift to translate or restore a single block on demand.
• Instant Selection Toolbar: Highlight any text on a webpage to pop up a compact action bar near your cursor—translate in place, explain the concept, or send the quote directly to the Sidekick side panel for follow-up questions.
• Bilingual Video Subtitles: Turn on dual-language subtitles directly from the video player control bar on YouTube, Bilibili, and standard HTML5 videos. Freely drag the subtitle box anywhere on the video and customize font size, color, and background opacity.
• Grounded Summaries for Web Pages, Videos & PDFs: Summarize long articles, video transcripts, and online or local PDF documents in seconds. Click any footnote citation or video timestamp to jump straight to the source paragraph or video moment.
• Multi-Step Browser Task Assistant: Ask Sidekick to help fill forms, navigate pages, or gather information in your active tab, with mandatory confirmation prompts before any sensitive action.
• Bring Your Own Key (100% Client-Side Privacy): Connect directly to OpenAI, Anthropic Claude, Google Gemini, DeepSeek, Kimi, Qwen, Zhipu GLM, OpenRouter, or local Ollama models. Your API keys and chat history stay in your browser—no account required and no intermediate servers.

How to Use:
1. Click the Sidekick icon in your browser toolbar to open the side panel and complete the quick 3-step API key setup.
2. Press Alt+A (or click the floating button on the right edge of the page) to toggle full-page bilingual translation.
3. Select any text on a webpage to use the floating Translate / Explain / Ask Sidekick toolbar.
4. Open the side panel anytime to summarize the current page, video, or PDF and ask follow-up questions.

Privacy & Permissions:
Sidekick operates entirely inside your browser. It only accesses pages when you interact with the extension or explicitly grant access to specific sites. Your API keys are stored locally on your device and are sent only to the AI provider endpoint you configure.

使用方式：

4. 随时在侧边栏一键总结当前网页、视频或 PDF 文档并进行多轮提问。

## Permissions Justification

| Permission | Type | Justification |
|------------|------|---------------|
| `sidePanel` | `permissions` | Displays the primary Sidekick AI assistant interface (page summaries, Q&A chat, translation controls, and settings) in Chrome's native Side Panel when the user clicks the toolbar icon or triggers "Ask Sidekick" from a webpage. |
| `storage` | `permissions` | Saves user preferences, custom translation prompts, and user-provided AI API keys locally on the device (`chrome.storage.local`), and passes one-time context menu or selection actions to the side panel via `chrome.storage.session`. |
| `activeTab` | `permissions` | Grants temporary access to the currently active tab only when the user explicitly clicks the toolbar icon, uses the keyboard shortcut (`Alt+A`), or selects a context menu item, allowing the extension to extract text for summarization or inject bilingual translations without requiring blanket access to all websites on install. |
| `scripting` | `permissions` | Injects the on-demand page translation, selection toolbar, and content extraction script into the active tab when requested by the user, avoiding permanent background scripts on every website. |
| `contextMenus` | `permissions` | Adds right-click menu shortcuts ("Translate this page", "Translate selected text", "Summarize this page", and "Ask Sidekick about selection") for quick access while reading. |
| `debugger` | `permissions` | Powers the optional, user-toggled Enhanced Browser Automation / MCP Bridge mode so advanced users can inspect console/network logs or execute high-fidelity page interactions in the active tab. It is disabled by default and only attaches when explicitly enabled by the user in Settings. |
| `userScripts` | `optional_permissions` | Requested only at runtime if the user enables custom automation scripts, allowing user-approved scripts to run in an isolated execution environment. |
| `<all_urls>` | `optional_host_permissions` | Requested only at runtime on a per-site basis (when the user enables "Auto-translate this site" or grants access to a specific domain/AI provider URL) or when the user explicitly toggles "Allow on all sites" in Settings → Data & Privacy. Never granted automatically at install time. |

## Privacy & Data Use

### Data Collection

**Does the extension collect user data?** No (Zero developer-operated servers or telemetry; all data stays in local browser storage and is sent directly from the user's browser to the user-configured AI API endpoint).

| Data Type | Collected by Developer? | Transmitted Off-Device? | Purpose | Shared with Third Parties? |
|-----------|------------------------|------------------------|---------|---------------------------|
| Personally identifiable info | No | No | — | No |
| Health info | No | No | — | No |
| Financial info | No | No | — | No |
| Authentication info | No (Stored locally in `chrome.storage.local` only) | Sent only in `Authorization` headers directly to the AI provider endpoint configured by the user | Authenticating the user's own API requests to their chosen LLM provider | Only with the user-selected AI provider |
| Personal communications | No | No | — | No |
| Location | No | No | — | No |
| Web history | No | No | — | No |
| User activity | No | No | — | No |
| Website content | No (Not collected by developer) | Selected text or current page paragraphs are sent directly to the user-configured AI provider only when the user triggers translation, summarization, or Q&A | Providing page translations, summaries, and answers requested by the user | Sent directly to the user-configured AI provider; never sent to developer servers |
